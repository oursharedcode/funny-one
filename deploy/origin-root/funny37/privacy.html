Privacy policy

Funny Multi is a party game for 3 to 7 players. This policy explains what happens to your information when you play it at www.funny37.oursharedcode.com or in its Android app.

In short: no accounts, no ads, no cookies, no tracking. The website keeps only anonymous daily visit counts. We do not sell or share your data.

While you play

  • The only thing you type is a nickname. The game server keeps it in memory only, shows it to the other players in your room and forgets it when the room closes. It never saves it and never sends it to an AI model.
  • You pick your answers from the game's own pre-written lists.
  • A room is deleted when its host ends the game, when everyone leaves or when the server restarts.
  • To prevent abuse, the server counts how often each IP address creates or joins rooms. These counts stay in memory for about a minute.
  • Our server keeps no access logs. If a request fails, the error log may contain the IP address involved; we use it only to fix the fault.

Pictures

  • Each finished story gets a cartoon, drawn by an AI image model from the game's pre-written phrases only — never from nicknames.
  • Cloudflare stores the pictures. Anyone with a picture's link can view it; pictures contain no personal information.
  • Your device loads the pictures directly from Cloudflare, so Cloudflare receives your IP address and browser details and may keep them for a short time in its technical logs.
  • We keep one anonymous number: how many pictures were made each day.

On your device

  • The game stores no cookies and no personal data on your device — only its own program files, so that it opens quickly.
  • Downloading or sharing a story happens on your device. The picture, its file name and the share text include the nicknames of the players in that room; you decide where they go.

Gifts (website only)

The website offers optional gifts, for example through GitHub Sponsors, Lightning or PayID. They open outside the game, only when you choose to use them, and those services' own privacy policies apply. The Android app does not offer gifts.

Visit counts (website only)

  • To learn whether the game finds its players, the website adds up anonymous counts per day: the game opened, its Support page opened and a gift option used — and, on the Funny Family page that introduces the game (www.funny-family.oursharedcode.com), its visits, the links followed and plays of its video.
  • Each count notes only the interface language, whether the visit came through the Funny Family page and which version of that page was shown; for that page's own visits, also the kind of site that linked to it (for example a search engine) and whether the screen is phone-sized.
  • The server keeps only these daily totals, for about 13 months — no IP address, no cookie, nothing that tells one visitor from another. To stop floods of counts, it holds each IP address in memory for about a minute, as it does for rooms.
  • Nothing is counted in the Android app, or when your browser sends Do Not Track or Global Privacy Control.

Service providers

  • Oracle Cloud (Sydney, Australia) runs the game server.
  • Cloudflare stores and delivers the pictures.

They process data on our behalf, only to run the game.

Children

The game is rated 12+ and is not directed at children under 13. It asks no one for personal information.

Security

Every connection to the game and to the pictures is encrypted (HTTPS).

Changes and contact

If this policy changes, this page will show the new date. Questions and requests: privacy@oursharedcode.com.

Під час гри

  • Кімната видаляється, коли ведучий завершує гру, коли всі виходять або коли сервер перезапускається.

சுருக்கமாக: கணக்குகள் இல்லை, விளம்பரங்கள் இல்லை, குக்கீகள் இல்லை, கண்காணிப்பு இல்லை. இணையதளம் அநாமதேய தினசரி வருகை எண்ணிக்கைகளை மட்டுமே வைத்திருக்கிறது. உங்கள் தரவை நாங்கள் விற்பதில்லை, பகிர்வதுமில்லை.

விளையாடும்போது

  • நீங்கள் தட்டச்சு செய்வது ஒரு புனைப்பெயர் மட்டுமே. விளையாட்டு சேவையகம் அதை நினைவகத்தில் மட்டுமே வைத்திருக்கிறது, உங்கள் அறையில் உள்ள மற்ற வீரர்களுக்குக் காட்டுகிறது, அறை மூடப்படும்போது அதை மறந்துவிடுகிறது. அதை ஒருபோதும் சேமிப்பதில்லை, எந்த AI மாதிரிக்கும் அனுப்புவதில்லை.
  • உங்கள் பதில்களை விளையாட்டில் முன்பே எழுதப்பட்ட பட்டியல்களிலிருந்து தேர்ந்தெடுக்கிறீர்கள்.
  • அறையை உருவாக்கியவர் விளையாட்டை முடிக்கும்போது, அனைவரும் வெளியேறும்போது அல்லது சேவையகம் மறுதொடக்கம் ஆகும்போது அறை நீக்கப்படும்.
  • தவறான பயன்பாட்டைத் தடுக்க, ஒவ்வொரு IP முகவரியும் எத்தனை முறை அறைகளை உருவாக்குகிறது அல்லது அவற்றில் சேர்கிறது என்பதைச் சேவையகம் எண்ணுகிறது. இந்த எண்ணிக்கைகள் சுமார் ஒரு நிமிடம் மட்டுமே நினைவகத்தில் இருக்கும்.
  • எங்கள் சேவையகம் அணுகல் பதிவுகளை வைத்திருப்பதில்லை. ஒரு கோரிக்கை தோல்வியடைந்தால், பிழைப் பதிவில் தொடர்புடைய IP முகவரி இருக்கலாம்; கோளாறைச் சரிசெய்ய மட்டுமே அதைப் பயன்படுத்துகிறோம்.

படங்கள்

  • முடிந்த ஒவ்வொரு கதைக்கும் ஒரு கார்ட்டூன் படம் கிடைக்கும். அதை AI பட மாதிரி விளையாட்டில் முன்பே எழுதப்பட்ட சொற்றொடர்களிலிருந்து மட்டுமே வரைகிறது — புனைப்பெயர்களிலிருந்து ஒருபோதும் இல்லை.
  • படங்களை Cloudflare சேமிக்கிறது. ஒரு படத்தின் இணைப்பு உள்ள எவரும் அதைப் பார்க்கலாம்; படங்களில் தனிப்பட்ட தகவல் எதுவும் இல்லை.
  • உங்கள் சாதனம் படங்களை நேரடியாக Cloudflare இலிருந்து ஏற்றுகிறது. எனவே Cloudflare உங்கள் IP முகவரியையும் உலாவி விவரங்களையும் பெறுகிறது, அவற்றைத் தனது தொழில்நுட்பப் பதிவுகளில் சிறிது காலம் வைத்திருக்கலாம்.
  • நாங்கள் வைத்திருப்பது ஒரே ஒரு அநாமதேய எண் மட்டுமே: ஒவ்வொரு நாளும் எத்தனை படங்கள் உருவாக்கப்பட்டன என்பது.

உங்கள் சாதனத்தில்

  • விளையாட்டு உங்கள் சாதனத்தில் குக்கீகளையோ தனிப்பட்ட தரவையோ சேமிப்பதில்லை — விரைவாகத் திறக்க அதன் சொந்த நிரல் கோப்புகளை மட்டுமே சேமிக்கிறது.
  • ஒரு கதையைப் பதிவிறக்குவதும் பகிர்வதும் உங்கள் சாதனத்திலேயே நடக்கின்றன. படம், அதன் கோப்புப் பெயர், பகிரும் உரை ஆகியவற்றில் அந்த அறையின் வீரர்களின் புனைப்பெயர்கள் இருக்கும்; அவை எங்கே செல்ல வேண்டும் என்பதை நீங்களே முடிவு செய்கிறீர்கள்.

அன்பளிப்புகள் (இணையதளத்தில் மட்டும்)

இணையதளம் விருப்ப அன்பளிப்புகளை வழங்குகிறது, எடுத்துக்காட்டாக GitHub Sponsors, Lightning அல்லது PayID மூலம். நீங்கள் பயன்படுத்தத் தேர்ந்தெடுக்கும்போது மட்டுமே அவை விளையாட்டுக்கு வெளியே திறக்கும்; அந்தச் சேவைகளின் சொந்தத் தனியுரிமைக் கொள்கைகள் பொருந்தும். Android செயலியில் அன்பளிப்பு வசதி இல்லை.

வருகை எண்ணிக்கை (இணையதளத்தில் மட்டும்)

  • விளையாட்டு அதன் விளையாட்டாளர்களைச் சென்றடைகிறதா என்பதை அறிய, இணையதளம் ஒவ்வொரு நாளும் அநாமதேய எண்ணிக்கைகளைக் கூட்டுகிறது: விளையாட்டு திறக்கப்பட்டது, "ஆதரவு" பக்கம் திறக்கப்பட்டது, அன்பளிப்பு வழி பயன்படுத்தப்பட்டது — மேலும் விளையாட்டை அறிமுகப்படுத்தும் பக்கத்தில் (www.funny-family.oursharedcode.com) வருகைகள், பின்தொடரப்பட்ட இணைப்புகள், வீடியோ இயக்கங்கள்.
  • ஒவ்வொரு எண்ணிக்கையும் இடைமுக மொழி, வருகை அறிமுகப் பக்கத்தின் வழியாக வந்ததா, அந்தப் பக்கத்தின் எந்தப் பதிப்பு காட்டப்பட்டது என்பதை மட்டுமே குறிக்கிறது; அந்தப் பக்கத்துக்கான வருகைகளுக்கு, இணைப்பு வந்த தளத்தின் வகையையும் (எ.கா. தேடுபொறி) திரை கைபேசி அளவிலானதா என்பதையும் குறிக்கிறது.
  • சேவையகம் இந்தத் தினசரி மொத்தங்களை மட்டுமே சுமார் 13 மாதங்கள் வைத்திருக்கிறது — IP முகவரி இல்லை, குக்கீ இல்லை, ஒரு பார்வையாளரை மற்றவரிடமிருந்து வேறுபடுத்தும் எதுவும் இல்லை. எண்ணிக்கைகள் வெள்ளமாக அனுப்பப்படுவதைத் தடுக்க, அறைகளுக்குச் செய்வது போலவே, ஒவ்வொரு IP முகவரியையும் சுமார் ஒரு நிமிடம் நினைவகத்தில் வைத்திருக்கிறது.
  • Android செயலியில் எதுவும் எண்ணப்படுவதில்லை; உங்கள் உலாவி Do Not Track அல்லது Global Privacy Control அனுப்பும்போதும் எண்ணப்படுவதில்லை.
