Privacy policy

Funny Multi is a party game for 3 to 7 players. This policy explains what happens to your information when you play it at www.funny37.oursharedcode.com or in its Android app.

In short: no accounts, no ads, no cookies, no tracking. The website and the Android app keep only anonymous daily visit counts, and a receipt log for each Christmas pack bought on the website. We do not sell or share your data.

While you play

  • The only thing you type is a nickname. The game server keeps it in memory only, shows it to the other players in your room and forgets it when the room closes. It never saves it and never sends it to an AI model.
  • You pick your answers from the game's own pre-written lists.
  • A room is deleted when its host ends the game, when everyone leaves or when the server restarts.
  • To prevent abuse, the server counts how often each IP address creates or joins rooms. These counts stay in memory for about a minute.
  • Our server keeps no access logs. If a request fails, the error log may contain the IP address involved; we use it only to fix the fault.

Pictures

  • Each finished story gets a cartoon, drawn by an AI image model from the game's pre-written phrases only — never from nicknames.
  • Cloudflare stores the pictures. Anyone with a picture's link can view it; pictures contain no personal information.
  • Your device loads the pictures directly from Cloudflare, so Cloudflare receives your IP address and browser details and may keep them for a short time in its technical logs.
  • We keep one anonymous number: how many pictures were made each day.

On your device

  • The game stores no cookies on your device — only its own program files, so that it opens quickly, and, on the website, the code of a Christmas pack whose link you opened (see “Christmas pack” below), until you remove it on the Home screen, and a code given to you to pay for by PayID, until you report the payment made. The Android app neither keeps nor sends these codes.
  • Downloading or sharing a story happens on your device. The picture, its file name and the share text include the nicknames of the players in that room; you decide where they go.

Gifts (website only)

The website offers optional gifts, for example through GitHub Sponsors, Lightning, PayID, Ko-fi or Buy Me a Coffee. They open outside the game, only when you choose to use them, and those services' own privacy policies apply. The Android app does not offer gifts.

Christmas pack (website only)

  • A Christmas pack bought on the website comes as a link with a code, such as XMAS26-K7QM-3FPA, which the website keeps on your device. A room created with it, or a room where any player uses it, plays all the Christmas stories. The Android app does not sell packs or read codes.
  • For each code the server keeps a receipt log: how it was paid for (PayID or GitHub Sponsors) or that it was our gift, the payment's reference and amount, where the code was delivered, which version of the refund terms was shown, when a PayID payment was reported and when it arrived, and whether the code was blocked (after a refund or a reversed payment, when it was shared beyond its family, or at the buyer's request).
  • Each room a code opens adds a line: the room's code, its language, how many players it had then, the country of the IP address that sent the code — looked up on the server, as for the visit counts; the address itself is not stored — and the browser's family, such as Firefox or Safari, without its version or any device details. Each game played with the pack adds its totals: the players, the rounds played, the answers picked, the cartoons made and how often stories were downloaded or shared. The log holds no nicknames, no answers and no IP addresses.
  • We use the log only to answer a buyer's question, to give a refund and to notice a code that has been shared widely (its rooms in many countries at once). Its records are deleted after 18 months, and it is not shared with anyone.
  • To stop codes from being guessed or hoarded, the server counts wrong codes, and the PayID codes it gives out, per IP address; these counts stay in memory for about an hour.

Visit counts

  • To learn whether the game finds its players, we add up anonymous counts per day: the game opened, on the website or in the Android app; on the website only, its Support page opened, a gift option used, a game begun in a room offered the Christmas stories (and whether its host switched them off), a Christmas story's cartoon seen, the Christmas pack's offer shown after a game, its payment page opened (from that offer or from a link) and its pay button pressed (for PayID or for GitHub Sponsors) — and, on the Funny Family page that introduces the game (www.funny-family.oursharedcode.com), its visits, the links followed, plays of its video, its Support page opened and the gift options used.
  • Each count notes only the interface language and whether the visit came through the Funny Family page (and which version of that page was shown) or from the Android app; for that page's own visits, also the kind of site that linked to it (for example a search engine) and whether the screen is phone-sized.
  • When the game or the Funny Family page is opened, the server also looks up the country of the IP address in a copy of DB-IP's free country database kept on the server itself — no outside service is asked — and adds one to that country's count for the day. The country counts are kept apart from the details above, and the address is not stored.
  • The server keeps only these daily totals, for about 13 months — no IP address, no cookie, nothing that tells one visitor from another. To stop floods of counts, it holds each IP address in memory for about a minute, as it does for rooms.
  • Nothing is counted when your browser sends Do Not Track or Global Privacy Control (the Android app runs in the phone's browser, usually Chrome).

Service providers

  • Oracle Cloud (Sydney, Australia) runs the game server.
  • Cloudflare stores and delivers the pictures.

They process data on our behalf, only to run the game.

Children

The game is rated 12+ and is not directed at children under 13. It asks no one for personal information.

Security

Every connection to the game and to the pictures is encrypted (HTTPS).

Politique de confidentialité

Pendant la partie

  • Notre serveur ne tient aucun journal des accès. Si une requête échoue, le journal d'erreurs peut contenir l'adresse IP concernée ; nous ne l'utilisons que pour corriger la panne.

Images

  • Chaque histoire terminée reçoit un dessin, créé par un modèle d'IA uniquement à partir des phrases rédigées à l'avance par le jeu — jamais à partir des pseudos.
  • Cloudflare stocke les images. Toute personne qui a le lien d'une image peut la voir ; les images ne contiennent aucune donnée personnelle.

L'application Android ne conserve ni n'envoie ces codes.

Dans une salle créée avec ce pack, ou dans une salle où n'importe quel joueur l'utilise, on joue toutes les histoires de Noël. L'application Android ne vend pas de packs et ne lit pas les codes.

Политика конфиденциальности

«Чепуха 37» (Funny Multi) — игра для компании из 3–7 человек. Здесь описано, что происходит с вашими данными, когда вы играете на www.funny37.oursharedcode.com или в приложении для Android.

Коротко: никаких аккаунтов, рекламы, cookie и слежки. Сайт и приложение для Android хранят только обезличенные счётчики посещений по дням и журнал каждого новогоднего набора, купленного на сайте. Мы не продаём и никому не передаём ваши данные.

Во время игры

  • Единственное, что вы вводите сами, — ник. Игровой сервер держит его только в памяти, показывает другим игрокам вашей комнаты и забывает, когда комната закрывается. Он никогда не сохраняет ник и не отправляет его ИИ-модели.
  • Ответы вы выбираете из заранее написанных списков игры.
  • Комната удаляется, когда ведущий завершает игру, когда все уходят или когда сервер перезапускается.
  • Чтобы не допустить злоупотреблений, сервер считает, как часто каждый IP-адрес создаёт комнаты или входит в них. Эти счётчики хранятся в памяти около минуты.
  • Наш сервер не ведёт журнал обращений. Если запрос завершился ошибкой, в журнале ошибок может оказаться соответствующий IP-адрес; мы используем его только для устранения неполадки.

Картинки

  • Каждая законченная история получает картинку, которую ИИ-модель рисует только по заранее написанным фразам игры — и никогда по никам.
  • Картинки хранит Cloudflare. Любой, у кого есть ссылка на картинку, может её открыть; персональных данных в картинках нет.
  • Ваше устройство загружает картинки напрямую из Cloudflare, поэтому Cloudflare получает ваш IP-адрес и сведения о браузере и может недолго хранить их в своих технических журналах.
  • Мы храним только одно анонимное число: сколько картинок создано за день.

На вашем устройстве

  • Игра не сохраняет на устройстве cookie — только собственные файлы программы, чтобы быстрее открываться, а на сайте ещё и код новогоднего набора, ссылку которого вы открыли (см. «Новогодний набор» ниже), пока вы не удалите его на главном экране, и код, выданный для оплаты через PayID, пока вы не сообщите, что оплатили. Приложение для Android такие коды не хранит и не отправляет.
  • Скачивание и отправка истории происходят на вашем устройстве. Картинка, имя файла и текст для отправки содержат ники игроков этой комнаты; куда их отправить, решаете вы.

Подарки (только на сайте)

プライバシーポリシー

おもしろストーリー（Funny Multi）は、3〜7人で遊ぶパーティーゲームです。このポリシーでは、www.funny37.oursharedcode.com または Android アプリでプレイするときに、あなたの情報がどう扱われるかを説明します。

プレイ中

  • あなたが入力するのはニックネームだけです。ゲームサーバーはそれをメモリ上にのみ保持し、同じルームの他のプレイヤーに表示し、ルームが閉じると破棄します。保存することも、AI モデルに送ることもありません。

  • ルームは、ホストがゲームを終了したとき、全員が退出したとき、またはサーバーが再起動したときに削除されます。
  • 不正利用を防ぐため、サーバーは各 IP アドレスがルームを作成・参加した回数を数えます。この回数はメモリ上に約 1 分間だけ保持されます。
  • 当サーバーはアクセスログを記録しません。リクエストが失敗した場合、エラーログに該当する IP アドレスが残ることがありますが、障害の修正にのみ使用します。

  • お使いの端末はイラストを Cloudflare から直接読み込むため、Cloudflare はあなたの IP アドレスとブラウザの情報を受け取り、技術ログに短期間保存することがあります。

Política de privacidade

Histórias Engraçadas (Funny Multi) é um jogo de festa para 3 a 7 pessoas. Esta política explica o que acontece com suas informações quando você joga em www.funny37.oursharedcode.com ou no app para Android.

Resumindo: sem contas, sem anúncios, sem cookies, sem rastreamento. O site e o app para Android guardam apenas contagens diárias e anônimas de visitas e um registro de recibos de cada pacote de Natal comprado no site. Não vendemos nem compartilhamos seus dados.

Durante o jogo

  • A única coisa que você digita é um apelido. O servidor do jogo o mantém só na memória, mostra para os outros jogadores da sua sala e o esquece quando a sala é fechada. Ele nunca o salva e nunca o envia a um modelo de IA.
  • Você escolhe suas respostas nas listas que o jogo já traz prontas.
  • Uma sala é apagada quando o anfitrião encerra o jogo, quando todos saem ou quando o servidor reinicia.
  • Para evitar abusos, o servidor conta quantas vezes cada endereço IP cria ou entra em salas. Essas contagens ficam na memória por cerca de um minuto.
  • Nosso servidor não mantém registros de acesso. Se uma solicitação falhar, o registro de erros pode conter o endereço IP envolvido; usamos isso só para corrigir a falha.

Imagens

  • Cada história concluída ganha um desenho, criado por um modelo de IA de imagens apenas a partir das frases prontas do jogo — nunca a partir dos apelidos.
  • A Cloudflare armazena as imagens. Qualquer pessoa com o link de uma imagem pode vê-la; as imagens não contêm dados pessoais.
  • Seu aparelho carrega as imagens diretamente da Cloudflare, então a Cloudflare recebe seu endereço IP e dados do navegador e pode guardá-los por pouco tempo em seus registros técnicos.
  • Guardamos apenas um número anônimo: quantas imagens foram criadas por dia.

No seu aparelho

  • O jogo não salva cookies no seu aparelho — apenas os próprios arquivos do programa, para abrir rápido, e, no site, o código de um pacote de Natal cujo link você abriu (veja “Pacote de Natal” abaixo), até você removê-lo na tela inicial, e um código dado a você para pagar por PayID, até você informar que o pagamento foi feito. O app para Android não guarda nem envia esses códigos.
  • Baixar ou compartilhar uma história acontece no seu aparelho. A imagem, o nome do arquivo e o texto compartilhado incluem os apelidos dos jogadores daquela sala; você decide para onde eles vão.

Doações (só no site)

  • بستهٔ کریسمسی که در وبسایت خریده شود به شکل یک لینک همراه با یک کد می‌رسد، مثل XMAS26-K7QM-3FPA، که وبسایت آن را روی دستگاه شما نگه می‌دارد. در اتاقی که با آن ساخته شود، یا اتاقی که هر یک از بازیکن‌هایش از آن استفاده کند، همهٔ قصه‌های کریسمس بازی می‌شوند. اپ اندروید بسته نمی‌فروشد و کدها را نمی‌خواند.
  • سرور برای هر کد یک گزارش خرید نگه می‌دارد: این‌که هزینهٔ آن چگونه پرداخت شده (PayID یا GitHub Sponsors) یا این‌که هدیهٔ ما بوده است، شمارهٔ مرجع و مبلغ پرداخت، این‌که کد به کجا تحویل داده شده، کدام نسخهٔ شرایط بازگرداندن پول نشان داده شده، چه زمانی پرداختی از راه PayID اعلام شده و چه زمانی رسیده است، و این‌که آیا کد مسدود شده است یا نه (پس از بازگرداندن پول یا برگشت خوردن پرداخت، وقتی که بیرون از خانواده‌اش به اشتراک گذاشته شده، یا به درخواست خریدار).

தனியுரிமைக் கொள்கை

வேடிக்கையான கதைகள் (Funny Multi) என்பது 3 முதல் 7 பேர் வரை விளையாடும் ஒரு குழு விளையாட்டு. www.funny37.oursharedcode.com இல் அல்லது அதன் Android செயலியில் நீங்கள் விளையாடும்போது உங்கள் தகவலுக்கு என்ன நடக்கிறது என்பதை இந்தக் கொள்கை விளக்குகிறது.

சுருக்கமாக: கணக்குகள் இல்லை, விளம்பரங்கள் இல்லை, குக்கீகள் இல்லை, கண்காணிப்பு இல்லை. இணையதளமும் Android செயலியும் அநாமதேய தினசரி வருகை எண்ணிக்கைகளையும், இணையதளத்தில் வாங்கப்பட்ட ஒவ்வொரு கிறிஸ்துமஸ் தொகுப்புக்குமான ரசீதுப் பதிவேட்டையும் மட்டுமே வைத்திருக்கின்றன. உங்கள் தரவை நாங்கள் விற்பதில்லை, பகிர்வதுமில்லை.

விளையாடும்போது

  • நீங்கள் தட்டச்சு செய்வது ஒரு புனைப்பெயர் மட்டுமே. விளையாட்டு சேவையகம் அதை நினைவகத்தில் மட்டுமே வைத்திருக்கிறது, உங்கள் அறையில் உள்ள மற்ற வீரர்களுக்குக் காட்டுகிறது, அறை மூடப்படும்போது அதை மறந்துவிடுகிறது. அதை ஒருபோதும் சேமிப்பதில்லை, எந்த AI மாதிரிக்கும் அனுப்புவதில்லை.
  • உங்கள் பதில்களை விளையாட்டில் முன்பே எழுதப்பட்ட பட்டியல்களிலிருந்து தேர்ந்தெடுக்கிறீர்கள்.
  • அறையை உருவாக்கியவர் விளையாட்டை முடிக்கும்போது, அனைவரும் வெளியேறும்போது அல்லது சேவையகம் மறுதொடக்கம் ஆகும்போது அறை நீக்கப்படும்.
  • தவறான பயன்பாட்டைத் தடுக்க, ஒவ்வொரு IP முகவரியும் எத்தனை முறை அறைகளை உருவாக்குகிறது அல்லது அவற்றில் சேர்கிறது என்பதைச் சேவையகம் எண்ணுகிறது. இந்த எண்ணிக்கைகள் சுமார் ஒரு நிமிடம் மட்டுமே நினைவகத்தில் இருக்கும்.
  • எங்கள் சேவையகம் அணுகல் பதிவுகளை வைத்திருப்பதில்லை. ஒரு கோரிக்கை தோல்வியடைந்தால், பிழைப் பதிவில் தொடர்புடைய IP முகவரி இருக்கலாம்; கோளாறைச் சரிசெய்ய மட்டுமே அதைப் பயன்படுத்துகிறோம்.

படங்கள்

  • முடிந்த ஒவ்வொரு கதைக்கும் ஒரு கார்ட்டூன் படம் கிடைக்கும். அதை AI பட மாதிரி விளையாட்டில் முன்பே எழுதப்பட்ட சொற்றொடர்களிலிருந்து மட்டுமே வரைகிறது — புனைப்பெயர்களிலிருந்து ஒருபோதும் இல்லை.
  • படங்களை Cloudflare சேமிக்கிறது. ஒரு படத்தின் இணைப்பு உள்ள எவரும் அதைப் பார்க்கலாம்; படங்களில் தனிப்பட்ட தகவல் எதுவும் இல்லை.
  • உங்கள் சாதனம் படங்களை நேரடியாக Cloudflare இலிருந்து ஏற்றுகிறது. எனவே Cloudflare உங்கள் IP முகவரியையும் உலாவி விவரங்களையும் பெறுகிறது, அவற்றைத் தனது தொழில்நுட்பப் பதிவுகளில் சிறிது காலம் வைத்திருக்கலாம்.
  • நாங்கள் வைத்திருப்பது ஒரே ஒரு அநாமதேய எண் மட்டுமே: ஒவ்வொரு நாளும் எத்தனை படங்கள் உருவாக்கப்பட்டன என்பது.

  • వెబ్‌సైట్‌లో కొన్న క్రిస్మస్ ప్యాక్, XMAS26-K7QM-3FPA లాంటి కోడ్ ఉన్న లింక్‌గా వస్తుంది; ఆ కోడ్‌ను వెబ్‌సైట్ మీ పరికరంలో ఉంచుతుంది. దానితో సృష్టించిన రూమ్‌లో గానీ, ఏ ఆటగాడైనా దాన్ని వాడే రూమ్‌లో గానీ అన్ని క్రిస్మస్ కథలూ వస్తాయి. Android యాప్ ప్యాక్‌లను అమ్మదు, కోడ్‌లను చదవదు.
  • ప్రతి కోడ్‌కు సర్వర్ ఒక రసీదు లాగ్‌ను ఉంచుతుంది: దానికి డబ్బు ఎలా చెల్లించారు (PayID లేదా GitHub Sponsors) లేదా అది మా కానుక అన్నది, చెల్లింపు రిఫరెన్స్, దాని మొత్తం, కోడ్‌ను ఎక్కడికి అందజేశారు, రీఫండ్ నిబంధనల ఏ వెర్షన్‌ను చూపించారు, PayID చెల్లింపు గురించి ఎప్పుడు తెలియజేశారు, అది ఎప్పుడు అందింది, కోడ్‌ను బ్లాక్ చేశారా అన్నది (రీఫండ్ లేదా చెల్లింపు వెనక్కి మళ్ళిన తర్వాత, అది తన కుటుంబం దాటి షేర్ అయినప్పుడు, లేదా కొన్నవారి అభ్యర్థన మేరకు).
  • ఒక కోడ్ తెరిచే ప్రతి రూమ్ ఒక పంక్తిని కలుపుతుంది: రూమ్ కోడ్, దాని భాష, అప్పుడు అందులో ఎంత మంది ఆటగాళ్ళు ఉన్నారు, కోడ్‌ను పంపిన IP చిరునామా ఏ దేశానిది — సందర్శనల లెక్కల్లో లాగే, సర్వర్ దీన్ని తన దగ్గరే చూస్తుంది; చిరునామాను మాత్రం నిల్వ చేయదు — అలాగే బ్రౌజర్ రకం, ఉదాహరణకు Firefox లేదా Safari, దాని వెర్షన్ గానీ పరికరం గురించిన ఏ వివరాలూ గానీ లేకుండా. ప్యాక్‌తో ఆడిన ప్రతి ఆట తన మొత్తాలను కలుపుతుంది: ఆటగాళ్ళు, ఆడిన రౌండ్లు, ఎంచుకున్న జవాబులు, తయారైన కార్టూన్లు, కథలను ఎన్నిసార్లు డౌన్‌లోడ్ లేదా షేర్ చేశారు అన్నది. లాగ్‌లో ముద్దుపేర్లు గానీ, జవాబులు గానీ, IP చిరునామాలు గానీ ఉండవు.
  • కొన్నవారి ప్రశ్నకు జవాబు ఇవ్వడానికి, రీఫండ్ ఇవ్వడానికి, విస్తృతంగా షేర్ అయిన కోడ్‌ను గుర్తించడానికి (ఒకేసారి చాలా దేశాల్లో దాని రూమ్‌లు) మాత్రమే మేము లాగ్‌ను వాడతాం. దాని రికార్డులు 18 నెలల తర్వాత తొలగించబడతాయి, అది ఎవరితోనూ పంచుకోబడదు.
  • కోడ్‌లను ఊహించకుండా లేదా పోగు చేసుకోకుండా అడ్డుకోవడానికి, సర్వర్ ప్రతి IP చిరునామాకు తప్పు కోడ్‌లను, ఇచ్చిన PayID కోడ్‌లను లెక్కిస్తుంది; ఈ లెక్కలు దాదాపు ఒక గంట పాటు మెమరీలో ఉంటాయి.

సందర్శనల లెక్కలు

  • ఆట తన ఆటగాళ్ళను చేరుకుంటోందో లేదో తెలుసుకోవడానికి, మేము రోజువారీ అనామక లెక్కలను కూడుతాం: వెబ్‌సైట్‌లో గానీ Android యాప్‌లో గానీ ఆట తెరిచిన సార్లు; వెబ్‌సైట్‌లో మాత్రమే, దాని “మద్దతు” పేజీ తెరిచిన సార్లు, కానుక మార్గం వాడిన సార్లు, క్రిస్మస్ కథలు అందించిన గదిలో ఆట మొదలైన సార్లు (హోస్ట్ వాటిని ఆపేశారా అన్నది కూడా), క్రిస్మస్ కథ కార్టూన్ చూసిన సార్లు, ఆట తర్వాత క్రిస్మస్ ప్యాక్ ఆఫర్ చూపించిన సార్లు, దాని చెల్లింపు పేజీ తెరిచిన సార్లు (ఆ ఆఫర్ నుంచా, లింక్ నుంచా అన్నది కూడా), దాని చెల్లింపు బటన్ నొక్కిన సార్లు (PayID కోసమా, GitHub Sponsors కోసమా అన్నది కూడా) — అలాగే ఆటను పరిచయం చేసే సరదా కుటుంబం (Funny Family) పేజీలో (www.funny-family.oursharedcode.com) సందర్శనలు, అనుసరించిన లింక్‌లు, దాని వీడియో ప్లే అయిన సార్లు; అక్కడ కూడా “మద్దతు” పేజీ తెరిచిన సార్లు, కానుక మార్గం వాడిన సార్లు.
  • ప్రతి లెక్క ఇంటర్‌ఫేస్ భాషను, సందర్శన సరదా కుటుంబం పేజీ ద్వారా వచ్చిందా (ఆ పేజీ ఏ వెర్షన్ చూపించారు అన్నదానితో సహా) లేక Android యాప్ నుంచి వచ్చిందా అన్నదాన్ని మాత్రమే నమోదు చేస్తుంది; ఆ పేజీకే వచ్చిన సందర్శనలకైతే, దానికి లింక్ ఇచ్చిన సైట్ రకాన్ని (ఉదాహరణకు సెర్చ్ ఇంజిన్), స్క్రీన్ ఫోన్ సైజులో ఉందా అన్నదాన్ని కూడా.
  • ఆట లేదా సరదా కుటుంబం పేజీ తెరిచినప్పుడు, సర్వర్ తన దగ్గరే ఉంచుకున్న DB-IP ఉచిత దేశాల డేటాబేస్ కాపీలో IP చిరునామా ఏ దేశానిదో కూడా చూస్తుంది — బయటి సేవ దేనినీ అడగకుండానే — ఆ దేశపు ఆ రోజు లెక్కకు ఒకటి కలుపుతుంది. దేశాలవారీ లెక్కలను పైన చెప్పిన వివరాల నుంచి వేరుగా ఉంచుతుంది, IP చిరునామాను మాత్రం నిల్వ చేయదు.
  • సర్వర్ ఈ రోజువారీ మొత్తాలను మాత్రమే, దాదాపు 13 నెలల పాటు ఉంచుతుంది — IP చిరునామా లేదు, కుకీ లేదు, ఒక సందర్శకుడిని ఇంకొకరి నుంచి వేరు చేసేదేదీ లేదు. లెక్కల వరదను ఆపడానికి, రూమ్‌ల విషయంలో లాగే, ప్రతి IP చిరునామాను దాదాపు ఒక నిమిషం పాటు మెమరీలో ఉంచుతుంది.
  • మీ బ్రౌజర్ Do Not Track లేదా Global Privacy Control పంపినప్పుడు ఏదీ లెక్కించబడదు (Android యాప్ ఫోన్ బ్రౌజర్‌లో నడుస్తుంది, అది సాధారణంగా Chrome అయి ఉంటుంది).

  • অপব্যবহার ঠেকাতে সার্ভার গুনে রাখে, প্রতিটি IP ঠিকানা থেকে কতবার রুম তৈরি করা হয় বা রুমে যোগ দেওয়া হয়। এই হিসাব প্রায় এক মিনিট মেমরিতে থাকে।
  • আমাদের সার্ভার কোনো অ্যাক্সেস লগ রাখে না। কোনো অনুরোধ ব্যর্থ হলে এরর লগে সংশ্লিষ্ট IP ঠিকানা থাকতে পারে; আমরা তা শুধু ত্রুটি সারাতে ব্যবহার করি।

ছবি

  • প্রতিটি শেষ হওয়া গল্পের জন্য একটি AI ইমেজ মডেল একটি কার্টুন আঁকে, শুধু গেমের আগে থেকে লেখা বাক্যাংশ থেকে — ডাকনাম থেকে কখনো নয়।
  • ছবিগুলো Cloudflare সংরক্ষণ করে। কোনো ছবির লিংক যার কাছে আছে, সে-ই ছবিটি দেখতে পারে; ছবিতে কোনো ব্যক্তিগত তথ্য থাকে না।
  • আপনার ডিভাইস ছবিগুলো সরাসরি Cloudflare থেকে লোড করে, তাই Cloudflare আপনার IP ঠিকানা ও ব্রাউজারের তথ্য পায় এবং অল্প সময়ের জন্য তা নিজের টেকনিক্যাল লগে রাখতে পারে।
  • আমরা শুধু একটি বেনামি সংখ্যা রাখি: প্রতিদিন কয়টি ছবি তৈরি হলো।

আপনার ডিভাইসে

  • গেমটি আপনার ডিভাইসে কোনো কুকি রাখে না — শুধু নিজের প্রোগ্রাম ফাইল রাখে, যাতে তাড়াতাড়ি খোলে, আর ওয়েবসাইটে, যে বড়দিনের প্যাকের লিংক আপনি খুলেছেন তার কোড (নিচে “বড়দিনের প্যাক” দেখুন), যতক্ষণ না আপনি শুরুর স্ক্রিনে সেটি মুছে ফেলেন, এবং PayID-তে পরিশোধের জন্য আপনাকে দেওয়া কোড, যতক্ষণ না আপনি পরিশোধ হয়ে গেছে বলে জানান। Android অ্যাপ এই কোডগুলো রাখেও না, পাঠায়ও না।
  • গল্প ডাউনলোড বা শেয়ার করার কাজ আপনার ডিভাইসেই হয়। ছবিতে, তার ফাইলের নামে আর শেয়ারের লেখায় সেই রুমের খেলোয়াড়দের ডাকনাম থাকে; সেগুলো কোথায় যাবে, তা আপনিই ঠিক করেন।

উপহার (শুধু ওয়েবসাইটে)

ওয়েবসাইটে ঐচ্ছিক উপহার দেওয়ার সুযোগ আছে, যেমন GitHub Sponsors, Lightning, PayID, Ko-fi বা Buy Me a Coffee-এর মাধ্যমে। এগুলো গেমের বাইরে খোলে, কেবল আপনি ব্যবহার করতে চাইলে, এবং সেসব সেবার নিজস্ব গোপনীয়তা নীতি প্রযোজ্য। Android অ্যাপে উপহারের ব্যবস্থা নেই।

বড়দিনের প্যাক (শুধু ওয়েবসাইটে)

  • ওয়েবসাইটে কেনা বড়দিনের প্যাক একটি লিংক হিসেবে আসে, যাতে XMAS26-K7QM-3FPA-এর মতো একটি কোড থাকে; ওয়েবসাইট কোডটি আপনার ডিভাইসে রাখে। এটি দিয়ে তৈরি রুমে, বা যে রুমে কোনো খেলোয়াড় এটি ব্যবহার করে সেখানে, সব ক্রিসমাসের গল্প খেলা হয়। Android অ্যাপ প্যাক বিক্রি করে না, কোডও পড়ে না।
  • প্রতিটি কোডের জন্য সার্ভার একটি রসিদ-লগ রাখে: কীভাবে দাম দেওয়া হয়েছে (PayID বা GitHub Sponsors) কিংবা সেটি যে আমাদের দেওয়া উপহার ছিল, পেমেন্টের রেফারেন্স ও পরিমাণ, কোডটি কোথায় পাঠানো হয়েছে, টাকা ফেরতের শর্তের কোন সংস্করণ দেখানো হয়েছিল, PayID পেমেন্টের কথা কখন জানানো হয়েছে আর সেটি কখন এসে পৌঁছেছে, এবং কোডটি ব্লক করা হয়েছে কি না (টাকা ফেরত বা পেমেন্ট ফিরিয়ে নেওয়ার পরে, কোডটি নিজের পরিবারের বাইরে শেয়ার হলে, কিংবা ক্রেতার অনুরোধে)।
  • কোনো কোড যে রুম খোলে, তার প্রতিটির জন্য একটি লাইন যোগ হয়: রুমের কোড, তার ভাষা, তখন তাতে কতজন খেলোয়াড় ছিল, কোডটি যে IP ঠিকানা থেকে এসেছে তার দেশ — ভিজিটের হিসাবের মতোই সার্ভারেই দেখে নেওয়া হয়; ঠিকানাটি নিজে রাখা হয় না — আর ব্রাউজারের ধরন, যেমন Firefox বা Safari, তার সংস্করণ বা ডিভাইসের কোনো তথ্য ছাড়া। প্যাক নিয়ে খেলা প্রতিটি গেম তার মোট হিসাব যোগ করে: খেলোয়াড়ের সংখ্যা, খেলা রাউন্ডের সংখ্যা, বেছে নেওয়া উত্তরের সংখ্যা, আঁকা কার্টুনের সংখ্যা এবং গল্পগুলো কতবার ডাউনলোড বা শেয়ার করা হয়েছে। লগে কোনো ডাকনাম, উত্তর বা IP ঠিকানা থাকে না।
  • আমরা লগটি শুধু ক্রেতার প্রশ্নের উত্তর দিতে, টাকা ফেরত দিতে এবং ব্যাপকভাবে শেয়ার হওয়া কোনো কোড চিহ্নিত করতে (যার রুম একসাথে অনেক দেশে) ব্যবহার করি। এর রেকর্ডগুলো 18 মাস পরে মুছে ফেলা হয়, আর লগটি কারও সাথে শেয়ার করা হয় না।
  • অনুমান করে কোড বের করা বা জমিয়ে রাখা ঠেকাতে সার্ভার প্রতিটি IP ঠিকানা থেকে আসা ভুল কোড এবং দেওয়া PayID কোড গুনে রাখে; এই হিসাব প্রায় এক ঘণ্টা মেমরিতে থাকে।

ভিজিটের হিসাব

  • গেমটি তার খেলোয়াড়দের কাছে পৌঁছাচ্ছে কি না জানতে, আমরা প্রতিদিনের বেনামি সংখ্যা যোগ করি: গেম খোলা হয়েছে, ওয়েবসাইটে বা Android অ্যাপে; শুধু ওয়েবসাইটে, এর “সমর্থন” পেজ খোলা হয়েছে, কোনো উপহারের উপায় ব্যবহার করা হয়েছে, ক্রিসমাসের গল্প দেওয়া ঘরে খেলা শুরু হয়েছে (আর হোস্ট সেগুলো বন্ধ করেছেন কি না), ক্রিসমাসের গল্পের কার্টুন দেখা হয়েছে, খেলার পরে বড়দিনের প্যাকের প্রস্তাব দেখানো হয়েছে, এর পেমেন্ট পেজ খোলা হয়েছে (সেই প্রস্তাব থেকে, না কোনো লিংক থেকে), এর পেমেন্ট বোতাম চাপা হয়েছে (PayID-এর জন্য, না GitHub Sponsors-এর জন্য) — আর গেমটির পরিচয় দেওয়া মজার পরিবার (Funny Family) পেজে (www.funny-family.oursharedcode.com) ভিজিট, অনুসরণ করা লিংক এবং এর ভিডিও চালানোর সংখ্যা; সেখানেও “সমর্থন” পেজ খোলা হয়েছে, কোনো উপহারের উপায় ব্যবহার করা হয়েছে।
  • প্রতিটি হিসাবে শুধু লেখা থাকে ইন্টারফেসের ভাষা এবং ভিজিটটি মজার পরিবার পেজ হয়ে এসেছে (আর সেই পেজের কোন সংস্করণ দেখানো হয়েছিল) নাকি Android অ্যাপ থেকে; সেই পেজের নিজের ভিজিটের ক্ষেত্রে আরও থাকে কোন ধরনের সাইট সেখানে লিংক দিয়েছে (যেমন কোনো সার্চ ইঞ্জিন) এবং স্ক্রিনটি ফোনের মাপের কি না।
  • গেম বা মজার পরিবার পেজ খোলা হলে, সার্ভার নিজের মধ্যেই থাকা DB-IP-এর বিনামূল্যের দেশ-ডেটাবেসের একটি কপিতে IP ঠিকানাটি কোন দেশের তাও দেখে নেয় — বাইরের কোনো সেবাকে জিজ্ঞেস না করেই — এবং সেই দেশের সেদিনের হিসাবে এক যোগ করে। দেশভিত্তিক হিসাবগুলো ওপরের তথ্য থেকে আলাদা রাখা হয়, আর IP ঠিকানাটি রাখা হয় না।
  • সার্ভার শুধু এই দৈনিক মোট সংখ্যাগুলো প্রায় 13 মাস রাখে — কোনো IP ঠিকানা নয়, কুকি নয়, এক ভিজিটরকে আরেকজন থেকে আলাদা করার মতো কিছুই নয়। একসাথে অজস্র গণনা ঠেকাতে, রুমের মতোই, এটি প্রতিটি IP ঠিকানা প্রায় এক মিনিট মেমরিতে রাখে।
