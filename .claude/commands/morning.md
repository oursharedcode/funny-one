Start of session. Read the RESUME HERE note at the foot of docs/IMPLEMENTATION_LOG.md
and git log since the last step. Propose the next step: which task, its exact scope
(grep tasks.md / tasks-done.md as needed), what "done" looks like (which of the six
gates apply, what needs in-browser verification), and anything that blocks it or that
I must decide as owner. Plan only — do not write code until I confirm.
