搞笑故事是一款适合 3 到 7 名玩家的派对游戏，每人使用自己的手机。一位玩家创建房间，其他人通过房间代码、链接或二维码加入，故事就开始了。

玩法
• 每一轮，大家为同一个有趣的问题选择答案：谁？还有谁？在哪里？什么时候？他们做了什么？为了什么？最后怎么样了？
• 每一轮故事都会传到下一位玩家手中，所以你总是在为一个看不到的故事添加内容。
• 七轮结束后，每个故事都会完整揭晓，并配上一幅搞笑的卡通图。
• 大家一起翻看房间的图库，然后下载或分享你最喜欢的。

功能特色
• 支持 23 种语言。在多语言房间里，每个人都用自己的语言玩。
• 所有答案都来自游戏自带的词库：除了昵称，什么都不用输入，也没有聊天。
• 无需账号，无广告，无应用内购买。
• 需要联网。也可以在任何手机的浏览器中玩，网址是 www.funny37.oursharedcode.com

隐私
你的昵称只保存在服务器的内存中，会显示给房间里的玩家，房间关闭后就会被忘掉。应用只记录匿名的每日访问次数，不记录任何能区分不同玩家的信息。隐私政策：https://www.funny37.oursharedcode.com/privacy

开源
搞笑故事是采用 GNU AGPL 3.0 的自由软件。源代码在 GitHub 上：https://github.com/oursharedcode/funny-one
